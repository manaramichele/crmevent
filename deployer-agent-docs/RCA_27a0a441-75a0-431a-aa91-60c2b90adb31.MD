## Root cause

do not exist in this deployment's production database OR in the source of the currently-live run.
The Super Admin screen being described is therefore served by a DIFFERENT environment/codebase than
this Emergent deployment (run 27a0a441) — or a newer saas-enabled version that was never deployed here.
Consequently there is nothing in THIS production DB for the code to recognize as an invoiceable Stripe
LIVE payment: the only invoice present is a single is_test=true credit_recharge.

`CRMEVENT_STRIPE_MODE=live` and `FIC_MODE=live`, and the DB holds only test/simulated data — consistent
with this environment being a test/seed dataset, not the real customer production store.
