# RCA — Deploy Run 18051aed-8836-4e59-a3bd-ad27a51810c8

## Summary
Redeploy of `manage-events-12` failed at the **build_image** step. The container image built successfully, but the **push to AWS ECR was denied** because the shared repository has reached its maximum image count. This is a **platform infrastructure/capacity issue** — not a source, manifest, secret, or tier problem.

## Failed Step
`build_image` (Cloud Build / AWS CodeBuild) — BUILD phase succeeded through image build; failed at export/push (step #51).

## Root Cause (proven)
The ECR repository ran out of allowed image slots:

```
#51 ERROR: failed to push 287883095218.dkr.ecr.us-west-2.amazonaws.com/customers-app:18051aed-8836-4e59-a3bd-ad27a51810c8:
denied: The repository with name 'customers-app' in registry with id '287883095218'
already has the maximum allowed number of images which is '100000'
```
- Classified by Cloud Build as `TerminalCloudBuildFailure, retryable: false`.
- Downstream noise: `imagetools inspect ... not found` in POST_BUILD is a consequence of the push never landing.

## Corroborating evidence
- Run history: runs at 08:03, 08:30, 08:49, and 10:35 UTC all pushed to the SAME `customers-app` repo successfully. The 10:41 run is the first to hit the 100,000-image ceiling — i.e., the shared repo just crossed the limit.
- No source/manifest change is implicated; the image built cleanly.

## Impact
- New code did NOT reach production.
- The previous successful run `895c2aa2-c61f-4f88-a93b-532b64982965` remains the active run — **the live app at https://manage-events-12.emergent.host is still up on the prior version.** No outage.

## Fix (Platform / Emergent infra)
- Prune/expire old images from the shared ECR repository `287883095218.dkr.ecr.us-west-2.amazonaws.com/customers-app` (add an ECR lifecycle policy), or raise the repository image quota.
- After the repo has free slots, re-run the deploy. No source or manifest edit is required.

## Not the cause
- Not application source (build succeeded).
- Not the manifest set (Dockerfile/entrypoint/nginx built and ran through the build).
- Not secrets, not tier, not the database, not domains.
